# 🚀 Java Learning Path

Este repositório serve como um diário cronológico dos meus estudos em desenvolvimento backend com Java, mostrando a evolução desde os conceitos básicos até as estruturas da Orientação a Objetos.

## 📂 Organização dos Capítulos:

* **`ch01_fundamentals`**: Sintaxe básica, estruturas condicionais e de repetição.
* **`ch02_arrays`**: Manipulação de vetores, encapsulamento e referências de memória.
* **`ch03_lists`**: Coleções dinâmicas utilizando a classe `ArrayList` e seus métodos.
* **`ch04_inheritance_polymorphism`**: Pilares avançados da Orientação a Objetos:
    * Reutilização de código usando `extends` e o construtor `super()`.
    * Sobrescrita de métodos com a anotação `@Override`.
    * Polimorfismo na prática ao criar uma lista única de `Product` que aceita as classes filhas.
    * Uso de constantes `private static final` para boas práticas de gerenciamento de memória e Clean Code.

## 🛠️ Tecnologias e Conceitos Trabalhados:
* Java moderno
* Programação Orientada a Objetos (POO)
* Boas práticas de nomenclatura (Clean Code)
